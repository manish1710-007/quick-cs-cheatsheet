Install first

Pick your system and copy the commands. Run them in a terminal, one block at a time.

Neovim 0.11+The editor. Older versions break LazyVim.
gitDownloads every plugin.
ripgrepSearches text in files: Space /.
fdFinds files by name: Space f f.
C compilerBuilds the syntax parsers that give you colors.
Node + npmMany language servers install through it.
lazygitOptional. Git screen on Space g g.
Nerd FontIcons. Without it you see empty boxes.
